## Background

Research notes often split across papers, notebooks, code repositories, and experiment folders. This project is a proposed information structure for keeping those artifacts connected without hiding the distinction between a source, an implementation, and an interpretation.

## Technical direction

The site treats each note as a small, typed record. A paper can be linked from a project, a project can point to a reproducibility log, and the log can preserve the exact state needed for a future run.
